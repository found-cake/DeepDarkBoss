# 고대도시탐방(?)
CSKWS 연합 CTF MISC 마인크래프트 문제 플러그인
- [SuperLegendPunch](https://github.com/found-cake/SuperLegendPunch)
- [DeepDarkBoss](https://github.com/found-cake/DeepDarkBoss)

## DeepDarkBoss 플러그인 기능
- 기본 이벤트 우선순위(NORMAL)기반 워든 엔티티에게 받는 데미지 이벤트 캔슬
- 워든 처치시 플래그 제공 및 게임 모드 변경
### Flag 저장 위치
플러그인 적용시 datafolder가 생성되고 **flag.txt** 파일 생성됨

해당 **flag.txt** 파일을 수정하여 flag 변경 가능


## 기타
jar파일 제공이며 CTF 특성상 의도적으로 dsl과 lamda를 이용하여 오버 엔지니어링을 진행하였다.
